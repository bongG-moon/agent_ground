매주 금요일 오후에 프로젝트 운영 담당자가 지난 1주일의 업무 진행 상황을 정리해 팀장과 관련 부서에 공유합니다.

현재 업무 방식은 다음과 같습니다.

1. Outlook에서 이번 주에 수신한 메일 중 제목 또는 본문에 프로젝트 코드, 고객사명, 장애, 일정, 검토 요청이 포함된 메일을 찾습니다. 자동 발송 알림, 회의 초대, 중복 전달 메일은 제외해야 합니다.
2. JIRA에서 이번 주에 변경된 이슈를 프로젝트별로 조회하고, 완료·진행 중·차단됨 상태와 담당자·마감일·우선순위를 정리합니다.
3. 회의록과 설계 문서에서 이번 주 결정 사항, 고객 요청, 다음 주에 확인할 Action Item을 찾습니다.
4. 메일·JIRA·문서의 내용을 프로젝트별로 합쳐서 완료 업무, 진행 중 업무, 이슈·리스크, 의사결정·변경사항, 다음 주 계획으로 분류합니다. 각 문장에는 가능한 경우 원본 메일 제목, JIRA 키, 문서 링크를 근거로 남겨야 합니다.
5. 데이터가 누락되었거나 동일 이슈가 여러 번 잡히면 담당자가 직접 확인할 수 있도록 후보와 이유를 표시합니다. 메일/JIRA 인증이 실패했거나 필수 근거가 없으면 최종 게시를 하면 안 됩니다.
6. 초안은 담당자가 민감정보, 고객사명 표기, 수치 누락, 리스크 표현을 검토한 뒤에만 사내 보고 포털에 게시합니다. 게시 후에는 팀장과 프로젝트 리더에게 보고서 링크와 핵심 이슈를 전달합니다.

완료 기준은 프로젝트별 주간 업무보고 초안이 근거 링크와 함께 준비되고, 사람이 검토·승인한 경우에만 게시 및 알림이 완료되는 것입니다.

입력으로는 Outlook 메일, JIRA 이슈, 회의록, 설계 문서, 프로젝트 담당자 목록이 필요합니다. 보고서는 Markdown 또는 HTML 형식으로 만들고, 포털 게시용 표와 팀장 알림용 짧은 요약도 필요합니다.
