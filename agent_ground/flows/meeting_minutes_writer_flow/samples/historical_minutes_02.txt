# 영업 예측 대시보드 데이터 품질 개선 회의록

- 일시: 2026-06-10
- 참석: 강부장, 오대리, 한과장, 배책임, 윤매니저
- 목적: 대시보드와 영업기획 집계의 금액 차이 원인을 제거하고 거래처 매핑, 품질 경고, 적재 상태, 권한 통제를 포함한 시범 운영 방안을 확정함

## 1. 현황 요약

- 5월 말 대시보드 월 예상 매출은 126억 원, 영업기획팀 수기 집계는 131억 원으로 5억 원 차이가 발생함.
- 주요 원인은 적재 기준 시각 불일치, CRM·ERP 거래처 코드 중복 및 누락, 해외 거래 환율 적용일 차이로 확인됨.
- 대시보드는 매일 오전 2시 적재분을 사용하지만 영업기획팀은 당일 오전 9시 CRM 자료를 사용하며, 화면 첫 부분에는 최종 적재 시각이 표시되지 않음.
- 거래처 매핑 오류는 43건이며 중복 반영 금액 2억 8천만 원, 연결 실패 누락 금액 1억 1천만 원으로 집계됨.
- 예상 종료일 누락은 전체 영업 기회의 7.4%, 확률이 기본값 50%인 건은 12.8%로 입력 품질 문제도 확인됨.
- 지난달 적재 실패가 두 번 발생했으나 화면에는 전날 데이터가 정상 데이터처럼 계속 노출됨.

## 2. 주요 논의

### 2.1 금액과 환율 기준

- 예상 매출과 확정 실적은 목적과 원천이 다르므로 하나의 계산 기준을 사용하지 않기로 함.
- 예측 금액은 매일 적재 시점의 전일 종가 환율로 환산함.
- 확정 실적은 ERP 전표의 원화 금액을 그대로 사용함.
- 예측 금액에는 적용 환율일과 통화 코드를 함께 저장하여 일별 변동 원인을 추적할 수 있게 함.
- 화면 상단에는 최종 적재 시각을 날짜, 시간, 시간대가 포함된 `YYYY-MM-DD HH:MM KST` 형식으로 표시함.
- 예상 매출과 확정 매출은 별도 컬럼으로 구분하고 각 기준을 툴팁으로 안내함.

### 2.2 거래처 매핑

- 현행 매핑 테이블에 유효 시작일, 유효 종료일, 매핑 상태, 변경 사유를 추가함.
- 과거 월을 다시 조회할 때 해당 시점에 유효했던 매핑을 사용하여 같은 결과를 재현할 수 있도록 적재 쿼리를 변경함.
- 영업기획 담당자가 변경을 요청하고 기준정보 담당자가 승인하도록 요청과 승인을 분리함.
- 요청자, 승인자, 승인 시각을 감사 로그에 기록함.
- 긴급 변경은 임시 상태로 등록하여 집계에는 포함하되 화면에 경고를 표시함.
- 미승인 상태는 노란색 아이콘과 상태 문구로 안내하고 다음 영업일 정오까지 승인되지 않으면 빨간색 상태와 운영 알림으로 전환함.
- 색상만으로 상태를 구분하지 않도록 아이콘과 텍스트를 함께 제공함.
- 금액 영향이 5천만 원 이상인 9건을 우선 정비하고 나머지는 최근 3개월 거래가 있는 건부터 처리함.

### 2.3 예측 품질 등급

- CRM 스키마 변경은 이번 범위에서 제외하고 대시보드에서 종료일, 확률, 최근 활동일을 조합하여 품질 등급을 계산함.
- 낮은 신뢰도는 단일 조건이 아니라 두 가지 이상 품질 조건을 충족한 경우로 제한함.
- 낮은 신뢰도 건도 총예측 금액에서 제외하지 않으며 금액과 비중을 별도 표시함.
- 사용자가 상세 화면에서 누락 필드와 낮은 등급 판정 사유를 확인할 수 있도록 함.
- 낮은 신뢰도 예측 금액 비중의 시범 목표는 현 추정 18%에서 12% 이하로 정하되 첫 주 결과에 따라 재조정할 수 있는 잠정 목표로 관리함.

### 2.4 적재 실패와 API 상태

- 적재 실패 시 화면에 마지막 성공 시각과 실패 상태를 표시함.
- 실패 10분 뒤 1차, 20분 뒤 2차 재시도를 수행하고 두 번 실패하면 운영 채널과 담당자 메일로 알림을 보냄.
- 장애 중에도 다운로드는 허용하되 파일에 데이터 상태, 기준 시각, 경고 내용을 포함함.
- API 응답에는 기존 필드를 변경하지 않고 선택 필드로 `data_status`, `last_success_at`, `warning_count`를 추가함.
- 시범 전 이전 버전 복구 절차를 연습하고 배포 스냅샷으로 30분 이내 복구할 수 있도록 함.

### 2.5 권한 통제

- 조직 개편 이후 사용자 그룹 반영이 하루 늦어져 다른 지역의 합계 금액이 보인 사례를 권한 위반으로 분류함.
- 장기적으로는 인사 시스템에서 예정 조직과 적용일을 받는 인터페이스가 필요함.
- 이번 범위에서는 영업지원팀이 조직 개편 전날 변경 목록을 제공하고 IT운영팀이 수동 반영한 뒤 다음 날 자동 검증함.
- 지역별·직급별 전용 테스트 계정 12개로 권한을 검증하며 실제 사용자 계정은 복제하지 않음.
- 보안팀 승인을 받은 테스트 계정만 사용함.

## 3. 의사결정

1. 예측 금액은 적재 시점 전일 종가 환율, 확정 실적은 ERP 원장 원화 금액을 사용함.
2. 최종 적재 시각과 환율 기준을 화면에서 직접 확인할 수 있게 함.
3. 거래처 매핑은 유효 기간과 승인 이력을 관리하고 과거 시점 재현이 가능하도록 변경함.
4. 긴급 미승인 매핑은 집계에 포함하되 승인 기한에 따라 경고 수준을 구분함.
5. 낮은 신뢰도 건을 총액에서 제외하지 않고 금액·비중·판정 사유를 별도 제공함.
6. 적재 실패는 두 번 재시도한 뒤 사용자 상태 표시와 운영 알림을 수행함.
7. 시범 대상은 수도권 영업1팀, 중부 영업2팀, 글로벌영업팀 총 32명으로 정함.
8. 시범은 2026-06-22부터 2026-07-03까지 진행하고 6월 26일 중간 점검, 7월 6일 최종 평가를 실시함.
9. 전사 확대는 자동으로 진행하지 않고 7월 6일 평가 회의에서 성공 기준 충족 여부를 확인한 뒤 결정함.
10. 금액 차이 2% 초과, 다른 지역 권한 노출, 적재 연속 3회 실패 중 하나가 발생하면 시범을 중단함.

## 4. 성공 기준

- 대시보드와 기준 집계의 금액 차이 0.5% 이하
- 거래처 중복·누락 경고 미처리 건 5건 이하
- 낮은 신뢰도 예측 금액 비중 잠정 12% 이하
- 적재 실패 30분 이내 감지 및 사용자 상태 표시
- 시범 사용자의 80% 이상이 기준 시각과 품질 경고를 과업 테스트에서 올바르게 이해
- 첫 화면 95백분위 응답 시간 5초 이하

## 6. 운영 방식

- 시범 문의는 전용 채널에서 받고 `데이터 오류`, `사용법`, `개선 요청` 태그로 구분함.
- 문의 현황은 매일 오후 4시에 공유함.
- 적재 장애 중 다운로드 파일에는 별도 데이터 상태 시트를 추가함.
- 시범 종료 후 사용 만족도만으로 확대하지 않고 모든 데이터 품질·권한·성능 기준을 함께 평가함.
- 금액 차이가 2%를 넘거나 권한 노출이 발생하면 즉시 이전 버전 복구 절차를 수행함.

## 7. 확인 필요

- 감사 로그 보관 기간: 1년을 제안했으나 보안팀 검토 전에는 미확정임.
- 인사 시스템 예정 조직 인터페이스: 장기 과제로 분리했으며 담당 부서와 일정은 미정임.
- 낮은 신뢰도 비중 12% 목표: 시범 첫 주 결과에 따라 현실성을 재검토함.

## 8. 회의록 작성 기준

- 원인, 결정, 검증 기준, 담당자와 기한이 연결되도록 안건별로 통합해 기록함.
- 확정되지 않은 목표와 장기 과제는 `확인 필요`로 분리함.
- 모바일 필터, 그래프 색상, 점심 메뉴 등 이번 데이터 품질 결정과 관계없는 내용은 제외함.
- 발언자별 대화 순서를 옮기지 않고 실제 실행에 필요한 정보 중심으로 요약함.
