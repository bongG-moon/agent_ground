# DRM 문서 텍스트 추출 Component 초보자 가이드

## 한 문장으로 이해하기

이 Component는 문서 파일을 읽을 수 있는 평문 텍스트로 바꿔 다음 요약·검색 단계에 전달합니다. 일반 문서는 로컬에서 먼저 읽고, 보호되어 읽지 못하는 문서는 조직에서 승인한 DRM text API로 보냅니다.

## “DRM 해제”라는 표현의 정확한 범위

이 Component는 복호화된 원본 PDF·PPT·Excel 파일을 사용자에게 내려주지 않습니다.

```text
원본 문서
  -> 로컬 텍스트 추출 시도
  -> 필요할 때 DRM text API 호출
  -> 평문 텍스트 또는 UTF-8 TXT 작업 파일
  -> 요약·검색·Chat Output
```

따라서 정확한 기능 이름은 `DRM 문서 텍스트 추출`입니다. 사내 DRM 정책을 우회하거나 보호된 원본 파일을 영구 복호화하는 도구로 사용하면 안 됩니다.

## 왜 이메일 Flow와 분리했는가

이메일 요약 이외에도 다음 업무에서 같은 기능을 재사용할 수 있기 때문입니다.

- 사용자가 직접 업로드한 PDF·PPT·Excel·Word 내용 읽기
- 문서 RAG 적재 전 텍스트 준비
- 첨부파일 요약 전 보호 문서 처리
- 승인된 내부 검색 시스템의 문서 본문 추출

`drm_document_text_extractor.py` 파일 하나를 Standalone Component로 등록할 수 있으며, 이메일 Flow는 이 공용 Component를 참조합니다.

## 입력 방식 두 가지

### 직접 파일 업로드

`문서 파일`에 여러 파일을 업로드하고 `추출된 문서 텍스트` Message 출력을 사용합니다.

```text
문서 파일
  -> DRM 문서 텍스트 추출
  -> extracted_text
  -> Chat Output 또는 요약 모델
```

### 이메일 첨부파일 처리

EWS Flow의 `file_path`, `file_name`, `source_kind`가 들어 있는 Data를 `EWS 파일 항목`에 연결하고 `처리된 파일` 출력을 사용합니다.

```text
EWS 첨부 Data
  -> DRM 문서 텍스트 추출
  -> processed_file
  -> Read File
  -> 요약 모델
```

## 처리 모드

| 모드 | 동작 | 권장 상황 |
| --- | --- | --- |
| `자동(로컬 우선)` | 로컬 추출 성공 파일은 그대로 처리하고 나머지만 DRM API 호출 | 일반 문서와 보호 문서가 섞인 경우 |
| `항상 DRM API` | 지원 문서를 모두 DRM API로 전송 | 보호 여부를 로컬에서 확실히 판별할 수 없는 경우 |
| `DRM 미사용` | 네트워크 호출 없이 로컬 지원 형식만 처리 | 샘플·비보호 문서 또는 오프라인 테스트 |

자동 모드는 공식 DRM 상태 조회가 아니라 로컬 파서 성공 여부를 사용합니다. 조직 DRM 정책상 모든 문서를 승인 서버에서 처리해야 한다면 `항상 DRM API`를 선택합니다.

## 필수 설정

DRM API를 사용할 때 다음 값을 설정합니다.

- `DRM API 주소`: 승인된 전체 URL
- `DRM 토큰`: Bearer 토큰
- `사번`: API의 `empNo` 값
- `TLS 인증서 검증`: 운영 환경에서는 켠 상태 유지

토큰과 사번은 Secret 입력이며 Flow JSON에 저장하지 않습니다.

## 처음 실행할 때

1. 먼저 보호되지 않은 TXT 또는 PDF 한 개로 `DRM 미사용` 모드를 시험합니다.
2. `extracted_text`에 문서 내용이 들어오는지 확인합니다.
3. 승인된 테스트 문서와 DRM API 설정을 준비합니다.
4. `항상 DRM API`로 테스트 문서 한 개를 실행합니다.
5. 오류·상태·로그에 토큰, 사번, 문서 본문이 노출되지 않는지 확인합니다.
6. 마지막으로 `자동(로컬 우선)`에서 일반 문서와 보호 문서를 함께 시험합니다.

## 보안상 반드시 확인할 것

- 문서 원본을 외부 인터넷 API로 보내지 않습니다.
- 승인된 사내 DRM endpoint만 사용합니다.
- HTTP는 원문과 토큰이 암호화되지 않으므로 기본 차단 상태를 유지합니다.
- 복호화된 평문 작업 파일의 저장 위치와 삭제 정책을 확인합니다.
- 오류 메시지에 API 응답 본문이나 문서 내용 전체를 넣지 않습니다.
- 실제 사내 DRM API 호출이 검증되기 전까지 `user_testing` 상태를 유지합니다.

## 자주 생기는 문제

### “DRM API 설정이 필요합니다”

자동 모드에서 로컬 추출에 실패했지만 API 주소·토큰·사번 중 하나가 비어 있습니다. 세 값을 모두 설정하거나 비보호 테스트라면 `DRM 미사용`을 선택합니다.

### HTTP 주소가 차단됩니다

기본 보안 동작입니다. 가능한 경우 HTTPS와 사내 CA를 사용합니다. 폐쇄 테스트망에서 HTTP만 가능한 경우에도 보안 승인 후 `HTTP DRM API 사용 허용`을 명시적으로 켭니다.

### ZIP 파일이 처리되지 않습니다

압축파일은 내부 파일을 자동으로 풀지 않습니다. 미지원 안내 결과를 반환하고 이메일 Loop의 다른 첨부 처리는 계속합니다.

### 결과가 원본 파일이 아닙니다

정상입니다. 이 Component의 목적은 복호화 원본 파일 배포가 아니라 평문 텍스트 추출입니다.
