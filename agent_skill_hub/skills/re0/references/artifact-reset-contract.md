# Artifact reset contract

Use this contract when a rewrite spans a long artifact or related files.

## Classify before editing

| Class | Treatment |
| --- | --- |
| Current authoritative rule | Preserve and clarify |
| Durable lesson | Move into its natural permanent section |
| Stale delta | Remove after verifying the newer truth |
| Duplicate | Keep the strongest complete occurrence |
| Contradiction | Resolve from authority or surface for a decision |
| Intentional history | Preserve in changelogs, decisions, audit records, and provenance |
| Unknown | Mark unresolved; never fill from model familiarity |

## Authority order

1. Current explicit user instruction
2. Protected product behavior and repository contracts
3. Canonical project documentation and tests
4. The target artifact
5. Nearby examples and inferred intent

Do not let a lower source silently override a higher one.

## Rewrite plan

For a substantial replacement, show:

```text
Target:
Protected content:
Remove:
Fold:
Conflicts:
Validation:
```

The user has already authorized an ordinary rewrite when the request clearly
names the artifact and desired result. Seek an additional decision only for an
unresolved authority conflict, a materially broader scope, or a destructive
replacement the request did not imply.

## Completion test

The result should stand alone for a reader with no access to the session. It
must not read as a cleanup log, retain old/new pairs, or add a new summary that
merely duplicates the rewritten body.
